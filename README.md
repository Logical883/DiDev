# DiDev

Corporate website for DiDev, operating under Mailiana-DiDev LTD.

```bash
npm install
npm run dev
```

Open the local address Vite prints. Production build:

```bash
npm run build
```

Inquiry mail is prepared in the browser and is not stored on a server. When a company mailbox is ready, set `contactEmail` in `src/content/site.ts`.
